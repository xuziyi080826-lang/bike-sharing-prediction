# 共享单车数据分析实验
## 实验现象观察
1. 使用 map() 方法完成季节文本到数字编码转换，生成新列Seasons_label，原始Seasons文本列保留，不会被修改覆盖。
2. value_counts() 统计Seasons_label，可以看到0、1、2、3各个季节标签对应的样本数量不相同，夏季样本数量最多。
3. train_test_split划分数据集，test_size=0.3代表30%样本作为测试集，70%作为训练集；设置random_state=42，多次运行代码，划分出来的数据集保持不变，实验可以复现。
4. 如果不配置 plt.rcParams["axes.unicode_minus"] = False，matplotlib绘图时坐标轴负号会显示为方块乱码，配置之后负号正常显示。
5. 自定义函数依靠return把DataFrame表格数据传回外部；函数内部的局部变量，在函数外部无法访问。
